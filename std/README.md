# 📜 标准聚合搜索器 (Standards Search)

这是一个小巧、极速且永远不会因为反爬虫而失效的终端工具。专为工业和材料科研人员设计。

它充当了一个“统一检索入口”：你在终端输入想要查询的标准名称或关键字，脚本会自动将其转化为各大权威标准数据库的精准检索链接，并**自动唤起你的默认浏览器**，帮你一次性在多个标签页中比对结果。

---

## 🚀 快速开始

进入脚本所在目录：
```bash
cd scripts/std
```

### 1. 🔍 一键聚合查询 (Search)

你可以输入中文或英文关键字。由于不同平台的语言偏好不同，建议根据你最关心的平台输入对应语言（例如查国标用中文，查 ASTM 用英文），或者中英混用。

```bash
# 格式：bun std.ts search "<搜索词>"

# 示例：搜索陶瓷抗折强度标准
bun std.ts search "陶瓷 抗折"

# 示例：搜索氧化铝粉末标准
bun std.ts search "Alumina powder"
```

运行后，终端会打印出所有生成的链接，并**自动打开浏览器**（Linux 下使用 `xdg-open`，macOS 下使用 `open`，Windows 下使用 `start`）分别访问以下平台：
1. **全国标准信息公共服务平台 (中国 GB/T 等)**
2. **国家标准全文公开系统 (可在线阅读原文)**
3. **国际标准化组织 (ISO)**
4. **美国材料与试验协会 (ASTM)**

---

## 💡 为什么要做成跳转聚合器？

中国国家标准平台缺乏公开的免费 API，且部署了严格的反爬虫机制（验证码、请求频率限制）。传统的终端爬虫不仅极易失效，还会因为频繁请求导致你的 IP 被官方封锁。
采用“终端构造精准 URL + 浏览器接管渲染”的模式，既保留了终端命令行的**快捷输入**优势，又完美利用了浏览器的**合法用户身份**，彻底绕过反爬，一劳永逸！
